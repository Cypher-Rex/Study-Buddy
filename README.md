# AI-Powered Study Buddy

An intelligent, interactive study helper that uses Groq’s LLaMA model and Streamlit to:  
- Explain concepts in simple terms  
- Summarize notes  
- Generate quizzes and flashcards  
- Act as an AI chat assistant for learning  

This repository contains the code, notebook, and deployment mechanism for Study Buddy.
